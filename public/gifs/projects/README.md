# Project Demo GIFs

Place your animated project demos here.

## Naming Convention
- Use lowercase with hyphens
- Be descriptive: `intelligent-flows-demo.gif`
- Format: `.gif` or `.webm`

## Suggested GIFs
- `intelligent-flows-demo.gif` - n8n workflow automation demo
- `prega-model-testing.gif` - MLOps model testing flow
- `empatia-detection.gif` - CT scan analysis animation

## Creating GIFs
Tools recommended:
- **ScreenToGif** (Windows) - https://www.screentogif.com/
- **LICEcap** (Cross-platform) - https://www.cockos.com/licecap/
- **Kap** (Mac) - https://getkap.co/

## Optimization Tips
- Keep GIFs under 5MB, ideally 2-3MB
- Limit to 15-30 seconds of content
- Reduce frame rate to 10-15 FPS for smaller files
- Consider WebP animated for better compression
