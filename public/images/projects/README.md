# Project Images

Place your project screenshots and images here.

## Naming Convention
- Use lowercase with hyphens
- Be descriptive: `intelligent-flows-dashboard.jpg`
- Recommended formats: `.jpg`, `.png`, `.webp`

## Suggested Images
- `intelligent-flows-dashboard.jpg` - n8n automation project screenshot
- `prega-mlops-interface.jpg` - MLOps platform dashboard
- `empatia-ct-scan.jpg` - Medical AI visualization

## Optimization Tips
- Use WebP format for better compression
- Keep images under 500KB if possible
- Recommended dimensions: 1920x1080 for full-width, 800x600 for cards
